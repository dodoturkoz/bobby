# Bobby

A native macOS 14+ personal finance scratchpad for quick maths, currency
conversions, and small finance calculations, with results that appear as you
type. Planned implementation: Swift, SwiftUI, and an AppKit editor.

Bobby is in the scope and planning stage. The intended first version focuses on
arithmetic, percentages, simple interest, and currency conversions. It accepts
both TL and TRY, uses English UI and number formatting, and supports Turkish
finance aliases. It is primarily for personal use, with possible sharing with
friends later.

See [PLANS.md](PLANS.md) for the proposed scope, milestones, and open decisions.
No application has been implemented yet.
